Methodology

Figures computed entirely from the SaSMaster spine: TMDB revenue/budget × OPUS-style categorical attributes (creative_type, source_type, production_method) × TMDB credit structs. Concept inspired by publicly-described people-value indexes (e.g. The Numbers Bankability Index) — no third-party report figures are embedded; every number above is derived directly from spine data.

The named join

Nielsen AA (AMRLD) → (NETWORK_ID, PCD) telecast key → nielsen_gn_identity_xref → IMDB_SERIES_ID → TMDB tmdb_id (via external_ids) → plot text via /tv/{id} + /tv/{id}/season/1

features_source: plot_text_v0 — series overview + up to 10 season-1 episode overviews from TMDB. This is marketing/summary copy, not dialogue or script — features are a proxy at best.

What would change this verdict

  • Larger n — 43 (up from 23 in v0) is still underpowered for detecting anything below a large effect size.
  • Actual dialogue/script text instead of plot summaries — overviews compress away most narrative signal.
  • Per-demo audience targets instead of total-persons durwt_aa — genre-correlated demos may hide feature effects that a blended metric averages out.
  • Time-series rather than a single cross-sectional 3-week Nielsen window.
  • Cleaner candidate set — Class A promotion is now LIVE (cert_run CLASSA_PROMOTE_20260725_SHIV_BLESS): the crosswalk fix is no longer an eval-only overlay, and candidate pools have been re-pulled at 20,000 movies / 200,000 series (see the coverage funnel above). This v0.1 run (n=43) predates the repull and still reflects the original overlay-corrected sample — re-running against the promoted pool is the next step.
